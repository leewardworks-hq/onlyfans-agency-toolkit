# Словарь агентства онлифанс и Fansly

Слова, которые в агентстве говорят каждый день, — простыми словами.

| Слово | Что значит |
|---|---|
| **OFM** | OnlyFans management: ведение аккаунтов авторов агентством — чаты, контент-план, продвижение, выплаты. |
| **Агентство** | Команда, которая ведёт аккаунты авторов за долю их заработка. |
| **Чатер** | Человек, который переписывается с фанами от имени автора и по его правилам: отвечает, ведёт разговор, предлагает платный контент. |
| **Тимлид** | Отвечает за смену: смотрит, кто в сети, помогает чатерам, следит за фанами, которые ждут ответа. |
| **Смена** | Часы, когда определённые чатеры ведут определённых моделей. |
| **Передача смены** | То, что уходящий чатер передаёт следующему: открытые диалоги, обещания, заметки. |
| **PPV** | Pay-per-view: сообщение с закрытым контентом, который фан открывает за деньги. |
| **Рассылка** | Одно сообщение сразу многим фанам, часто с PPV. |
| **Хранилище (vault)** | Библиотека контента автора, который чатеры прикрепляют к сообщениям. |
| **Кит** | Фан, который тратит намного больше остальных. |
| **Чаевые** | Деньги, которые фан отправляет без покупки конкретного контента. |
| **Подписка** | Ежемесячная цена, которую фан платит, чтобы следить за автором. |
| **Ребилл** | Автоматическое продление подписки; фаны с выключенным ребиллом могут уйти в конце периода. |
| **Возврат / чарджбэк** | Деньги, возвращённые фану, или платёж, который оспорил банк фана. |
| **Время ответа (медиана)** | Сколько обычно ждут ответа фаны. Медиану меньше искажают несколько очень долгих ответов, чем среднее. |
| **Ссылка отслеживания** | Ссылка, по которой видно, из какой рекламы пришёл новый фан. |
| **FYP** | Лента «For You» в Fansly: витрина, где новые фаны находят автора. |
