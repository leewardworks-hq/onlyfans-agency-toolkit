# Словник агенції онліфанс і Fansly

Слова, які в агенції кажуть щодня, — простими словами.

| Слово | Що означає |
|---|---|
| **OFM** | OnlyFans management: ведення акаунтів авторів агенцією — чати, контент-план, просування, виплати. |
| **Агенція** | Команда, яка веде акаунти авторів за частку їхнього заробітку. |
| **Чатер** | Людина, яка листується з фанами від імені автора і за його правилами: відповідає, веде розмову, пропонує платний контент. |
| **Тімлід** | Відповідає за зміну: дивиться, хто в мережі, допомагає чатерам, стежить за фанами, які чекають на відповідь. |
| **Зміна** | Години, коли певні чатери ведуть певних моделей. |
| **Передача зміни** | Те, що чатер, який іде, передає наступному: відкриті діалоги, обіцянки, нотатки. |
| **PPV** | Pay-per-view: повідомлення із закритим контентом, який фан відкриває за гроші. |
| **Розсилка** | Одне повідомлення одразу багатьом фанам, часто з PPV. |
| **Сховище (vault)** | Бібліотека контенту автора, який чатери прикріплюють до повідомлень. |
| **Кит** | Фан, який витрачає набагато більше за інших. |
| **Чайові** | Гроші, які фан надсилає без купівлі конкретного контенту. |
| **Підписка** | Щомісячна ціна, яку фан платить, щоб стежити за автором. |
| **Ребіл** | Автоматичне продовження підписки; фани з вимкненим ребілом можуть піти наприкінці періоду. |
| **Повернення / чарджбек** | Гроші, повернуті фану, або платіж, який оскаржив банк фана. |
| **Час відповіді (медіана)** | Скільки зазвичай чекають на відповідь фани. Медіану менше спотворюють кілька дуже довгих відповідей, ніж середнє. |
| **Посилання відстеження** | Посилання, за яким видно, з якої реклами прийшов новий фан. |
| **FYP** | Стрічка «For You» у Fansly: вітрина, де нові фани знаходять автора. |
